## Performance Breakdown

- **Line 57 (180ms)**: `c.set.Add(word)` in loop

  - Hash computation + insertion
  - 31% of total CPU time

### 2. Memory Allocation (41% of CPU)

## Optimization Opportunities

### Immediate (High Impact)
1. **Replace StringSet with sorted array + binary search**
   - Trade O(1) insert for O(log n) search
   - Avoid hash computation overhead
   - Estimate: 50-70% reduction in map time

2. **Pre-allocate map capacity**
   - `NewStringSet(elemsCount)` instead of `NewStringSet(0)`
   - Reduces map growth/rehashing
   - Estimate: 10-15% reduction

### Advanced (Very High Impact)
3. **Use bloom filter for fast negative checks**
   - Check bloom first before map insertion
   - Skip duplicates without map access
   - Estimate: 30-40% reduction if many duplicates

4. **Two-pass algorithm**
   - First pass: count unique (no map, just array scan)
   - Only use map if threshold might be met
   - Estimate: varies by input

## Recommendation

**Start with #1**: Replace StringSet with sorted slice approach
- Simple to implement
- No external dependencies
- Predictable performance
- Better cache locality
