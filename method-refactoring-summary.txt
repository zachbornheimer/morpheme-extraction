## Architectural Solution: Proper Package Abstraction

The circular dependency was solved by following Go's package architecture rules:

### Abstraction Layers

1. **structs package** - Pure data structures + simple methods
   - No internal package imports
   - Only simple data manipulation (AddWord, Add, AddElement, AddSimilarRef)
   
2. **Domain packages** - Complex business logic as functions
   - morpheme_t: GenRegex, MergeRules
   - morpheme_list_t: FindInternalMorphemes, FuseRegex, IdentifyTrueMorphemes
   - ngram_t: Uniqify
